使用步骤

1. 打开电台，不要进 bootloader，也不要锁屏
所有命令都由运行中的固件处理；锁屏或 bootloader 状态下电台不会响应。
2. 连接（Chrome / Edge，Web Serial）
点“连接电台”，在弹窗里选电台对应的串口（UART 桥是 38400；USB CDC 只需选口）。 连上后底部状态栏会显示固件版本。
3. 先“读取电台”，再改，最后“写回改动”
只有被修改过的信道会被写入，没动过的字节不会碰。
3b. 调整信道顺序
电台是按信道号（槽位）扫描和切换的，所以“顺序”就是每条信道待在哪个信道号。
• 拖动：抓住左边信道号前的 ⠿ 拖到目标行， 上半格＝放在它前面，下半格＝放在它后面。
• 一行一行挪：行尾的 ↑ ↓ 和相邻信道交换位置。
• 一步到位：展开 ▸，里面有“移到最前 / 移到最后 / 移到信道号…”。
• 整批排序：工具栏的“排序”可以按频率（低→高 / 高→低）或名称重排。
拖动和排序都只作用于当前显示的那些行：勾上“显示全部 1024 条”时是整个信道表， 用搜索过滤时只有过滤出来的行参与重排，其余信道原地不动。
顺序改动只在点“写回改动”之后才进电台；被挪动的信道会被重写一遍， 所以大范围调整前先“导出 JSON”备份。
4. 写入后点“重启电台”让新信道生效
电台不会自动重读信道表，重启最稳妥。

注意事项

务必先备份
“读取电台”之后用“导出 JSON”存一份，出问题可以对照恢复。 导出的是编辑区当前的内容（含还没写回电台的改动和刚调好的顺序）， 每条都带信道号，所以导入回来顺序也一起恢复。
名称编码
信道名是 UTF-8，占 15 字节（一个汉字 3 字节）。工具会按字符边界截断，绝不会写入半个汉字。 中文名在这里用系统输入法直接输入即可；电台上只能改（删字、把汉字换成字母），不能新增汉字。
多启动（Multiboot）
写入的是“当前生效的那个配置库”。如果你用多启动切换过配置库，写之前先确认电台当前用的是哪一个。
字库与固件
字库相关命令（0x0740/0x0742/0x0744）只在带 ENABLE_CHINESE 的固件里存在； 否则“刷新字库状态”会报无响应。字库放在外部 Flash，刷固件不会丢。
不要用本工具做“整片 flash 刷写”
它只写信道区、信道名区和字库区，不动校准数据、不动多启动槽位。
